# drafts

管理画面や operator MCP で本番に入れる前の原稿を置く場所です。記事の正本は本番 D1 なので、ここに置いた原稿は公開されません。

- 原稿は `drafts/<テーマ>/` にまとめる。
- 本番に反映し終わったフォルダは消す（本番の本文が先に進むので、残すと古い写しになる）。中身は Git の履歴に残る。

いまあるもの:

| フォルダ                 | 中身                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| `tabisaki-no-kobanashi/` | シリーズ「旅する雑学」の原稿、編集方針（v1.0〜v1.2）、事実確認の記録 |
