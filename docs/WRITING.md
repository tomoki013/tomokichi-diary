# 記事の書き方（型を作らない）

2026-11-05、本人の判断で決めた方針。記事を書く・書き直す AI と人のどちらにも適用する。

記事が「AIが書いたっぽい」「面白くない」と感じられた一番の原因は、構成・字数・見出し数・締め方を**型として指示していた**ことだった。型を渡すと、どの記事も同じ形になり、本人の声が消える。だから、型は作らない・渡さない。

## やらないこと

- **決まった構成を指示しない。** 「景色の導入 → 答え → 背景 → 旅とのつながり」「結論 → 手順 → まとめ」のような流れを決めない。その記事で一番おもしろいところから書き始める。
- **字数・小見出しの数を目標にしない。** 「1,000〜1,500字」「小見出し2〜3個」のような目安で書かない。短くて済む話は短く書く。
- **冒頭の要約を書かない。** 「この日は〜な1日だった。〜もはっきり残った」で始めない。
- **締めの決まり文句を書かない。** 「〜な1日だった。翌日は〜へ向かう」「いかがでしたか」「ぜひ〜してみてください」「次に訪れるときは〜に目を向けてみたい」で終えない。
- **段落の最後に一般論を足さない。** 「旅って〜なところがある」「こういう〜のほうが〜」のような、誰にでも言える感想で段落を閉じない。
- **タイトルを同じ型で揃えない。** 「〜を浴びた日」「〜に削られた日」「〜は、実は〜？ 〜の秘密」のように全記事を同じ形にしない。その記事の一番の出来事をそのまま書く。
- **定型の強調を使わない。** 「**実は〜なのです。**」の太字、「つまり〜」での言い換え、「まとめ」見出しを癖で入れない。
- **使いがちな言葉を多用しない。** 忘れられない／印象的／魅力／特別な／〜を感じさせる／息をのむ／輪郭／掴む／浴びる／振れ幅／削られる／醍醐味。

## やること

- **本人の記録にあることだけを書く。** 出来事・数字・その場の気持ち・理由・情景描写を足さない。「ベンチで寝た」のか「床で寝た」のか分からないなら、書かないか本人に聞く。
- **本人の口調で書く。** 旅行記は常体で、関西弁やツッコミ（「こんなんちゃう」「学習してない」「有識者の方、教えてください」）を残す。ガイドや雑学はです・ます調でよいが、本人の体験を必ず軸にする。
- **おもしろいところを先に出す。** やらかし、予想外、数字（8バーツ、4万歩、1分差）など、本人にしか書けないところを前に出す。
- **書き直しは下書きで保存する。** 公開は本人が確認してから。
