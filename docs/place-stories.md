# 記事詳細の「この場所の小話」

シリーズの識別は表示名ではなく `travel-stories`。公開済みの「旅先の小話」から、記事に登場する具体的な場所についての小話だけを本文下に最大4本表示します。対象がなければセクション自体を出しません。小話22本の公開・予約は行いません。

判定は `ContentIndex.placeStoriesFor` と `read/place-stories.ts` に集約します。

- CMSのスポットIDが共通なら一致。国・地域・都市の関連付けだけでは一致しません。
- 既存22テーマは編集上の対象スポットと表記揺れを定義し、公開版のタイトル・本文にその場所が出てくるかを照合します。
- サントリーニの白い家やカッパドキアの奇岩などは、地域名に加えて対象の景色への言及が必要です。文脈は同じ段落・見出し・記事タイトルの範囲とし、別の場所についての記述を混ぜません。
- マレーシアのブルーモスクをイスタンブールと取り違えず、マリーナベイ・サンズというホテル名だけを貯水池の話に結び付けません。
- 画像の代替テキスト、関連記事リンク、参考資料、コメント、コードは場所への言及として扱いません。本文中の通常のリンクは、その表示テキストを読みます。
- 下書き・予約前・非公開の小話は表示しません。公開記事の未公開改稿にだけある場所も表示条件に使いません。

新テーマは具体的なCMSスポットを設定するか、対象スラッグと固有名を判定表へ追加します。広い地域名だけの条件は追加しません。シリーズ名の変更には追従しますが、シリーズのスラッグ・各記事のスラッグを変更するときは判定表も更新します。

小話は一般的な「同じ国」「似た体験」「関連記事」候補から除外し、この専用セクションに集約します。シリーズ一覧や通常のシリーズ内ナビゲーションは維持します。
